Whether a cycle throws at all depends on which module you enter from, so no browser check is reliable for cycles — run node test-onyx/check-cycles.mjs, which decides it statically. This page catches the rest: top-level code that assumes a bundler shim, a bad specifier, a module that throws on evaluation.
